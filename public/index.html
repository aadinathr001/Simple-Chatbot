About This Project

🎯 Overview

This portfolio project demonstrates a production-grade, secure LLM client-server architecture built to showcase rapid inference using Groq and the open-weight openai/gpt-oss-20b model.

🏗️ Architecture

[Browser Client] ➔ [Express Proxy / Rate Limiter] ➔ [Groq API] ➔ [gpt-oss-20b]

Key Security Principle: The Groq API key is stored exclusively in backend environment variables (never in frontend code or bundle), preventing token leakage.

🛡️ Built-in Safeguards

  • Rate Limiting: IP-based request throttling using express-rate-limit to safeguard free-tier quota.
  • Input Validation: Server-side 500-character input capping and schema sanitation.
  • Context Management: Multi-turn conversation window maintaining relevant conversation context while capping token consumption.

⚙️ Tech Stack

Node.js Express.js Groq Cloud API openai/gpt-oss-20b Modern CSS/HTML Render Hosting
